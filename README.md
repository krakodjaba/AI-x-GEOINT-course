# AI × GEOINT

## Local AI Pipeline & Practical GEOINT Analytics

Материалы по применению локальных AI-систем в **OSINT / GEOINT**, построению AI-GEOINT pipeline и подготовке структурированного GEOINT-отчёта.

Это расширенный комплект материалов по трём направлениям, которые разбирались на прошедшем курсе GEOINT.

Внутри — полноценные записи live-лекций, презентации, расширенные методические материалы и пример итогового GEOINT-отчёта.

## Лекции

### 01 / Local AI Pipeline for OSINT & GEOINT

Архитектура локального AI pipeline и применение локальных AI-инструментов в задачах OSINT и GEOINT.

Рассматриваются:

* локальные LLM / VLM;
* inference pipeline;
* взаимодействие AI-компонентов;
* обработка и анализ OSINT-данных;
* применение AI в GEOINT workflow.

---

### 02 / AI-GEOINT Pipeline

#### Street Image Geolocation System

```text
Image → VLLM → LLM → Output
```

Разбор базовой архитектуры системы автоматической геолокации изображений с использованием vision-модели и локального inference.

Основной фокус:

* анализ street-level imagery;
* извлечение визуальных признаков;
* использование VLM для интерпретации изображения;
* передача результатов в LLM;
* формирование итогового геолокационного вывода;
* построение воспроизводимого AI-GEOINT pipeline.

---

### 03 / From Raw Data to GEOINT Report

Переход от разрозненных исходных данных к структурированному аналитическому документу.

```text
Collection
    ↓
Verification
    ↓
Analysis
    ↓
Assessment
    ↓
Conclusions
    ↓
GEOINT Report
```

Разбирается логика подготовки итогового GEOINT-результата:

* сбор исходных данных;
* верификация;
* корреляция информации;
* аналитическая обработка;
* формирование выводов;
* структурирование результатов;
* подготовка итогового отчёта.

## Что является результатом

Основная идея материала — показать не отдельный AI-инструмент, а **полный аналитический workflow**.

От:

```text
RAW DATA
```

через:

```text
AI PIPELINE
↓
VERIFICATION
↓
ANALYSIS
```

к:

```text
STRUCTURED GEOINT REPORT
```

То есть AI рассматривается не как конечный результат, а как компонент воспроизводимого аналитического процесса.
